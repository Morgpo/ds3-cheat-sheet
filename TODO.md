| Build                               | Playstyle                                                                                                                   |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **1. Quality Build (STR/DEX)**      | Flexible weapon master. Uses weapons that scale well with both Strength and Dexterity; great for trying many melee options. |
| **2. Strength Build (STR)**         | Heavy-hitter bruiser. Uses greatswords, ultra weapons, hammers, and axes to trade blows and stagger enemies.                |
| **3. Dexterity Build (DEX)**        | Fast and technical. Uses katanas, curved swords, spears, and quick weapons with aggressive dodging.                         |
| **4. Pure Sorcerer (INT)**          | Long-range magic caster. Focuses on powerful sorceries, spacing, and deleting enemies before they get close.                |
| **5. Pyromancer (INT/FTH)**         | Versatile spellblade/caster. Uses fire and dark magic with strong damage variety and good melee options.                    |
| **6. Miracle Build (FTH)**          | Faith-based fighter. Uses lightning attacks, healing, buffs, and defensive tools; stronger later in the game.               |
| **7. Dark Build (INT/FTH Melee)**   | PvP-oriented hybrid. Uses Dark/Chaos infused weapons to exploit defenses with strong melee pressure.                        |
| **8. Bleed/Luck Build (LCK)**       | Status attacker. Uses fast weapons to rapidly build bleed and chunk enemy health instead of relying on raw hits.            |
| **9. Hollow Build (LCK Hybrid)**    | Scaling-focused Luck build. Uses Hollow-infused weapons and buffs for high physical damage and bleed synergy.               |
| **10. Battle Mage (STR/DEX + INT)** | Magic knight. Mixes melee combat with sorcery buffs, utility spells, and magic-infused weapons.                             |
| **11. Paladin Build (STR/FTH)**     | Tanky holy warrior. Combines heavy weapons, armor, lightning buffs, healing, and survivability.                             |
| **12. Glass Cannon Build**          | Maximum offense, minimum safety. Dumps stats into damage for huge burst while relying on perfect dodging.                   |
